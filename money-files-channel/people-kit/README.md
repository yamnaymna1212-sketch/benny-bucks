# مكتبة الشخصيات (People kit)

## الفكرة
تبني مرة واحدة مكتبة قصاصات لكل شخصية أو شركة تتكرر في قصصك، ثم يستخدمها Claude Code تلقائيًا في كل فيديو.

## الخطوات
1. نزّل الصورة بنفسك من مصدر مرخّص (Wikimedia Commons، صور رسمية للحكومة الأمريكية غالبًا ملك عام، أو صورة تملكها) وضعها في `assets/people/raw/`.
2. أضف إدخالًا في `assets/people/people.json`: الاسم، الأسماء البديلة التي تظهر في السكريبت، اسم الملف، الرخصة، رابط المصدر، وسطر الإسناد إن لزم.
3. شغّل: `python build_library.py assets/people gray` (أو `halftone`).
4. تظهر القصاصات في `assets/people/cutouts/` بإطار أحمر وظل.

## لماذا يطلب الملف الرخصة والمصدر
حتى إذا وصلتك مطالبة حقوق على صورة، تعرف من أين جاءت وبأي رخصة، وتستطيع الرد.

## إزالة الخلفية
إن كانت الصورة بلا شفافية، يحتاج `cutout.py` الحزمة: `pip install rembg onnxruntime`.
أو أعطه PNG شفافًا جاهزًا.

## للـ Claude Code
اقرأ `people.json`. عندما يذكر السكريبت اسمًا أو اسمًا بديلًا لشخص له `cutout`، ضع القصاصة في المشهد بستايل الكولاج الورقي. إن لم يكن له `cutout`، استخدم رمزًا مجردًا (ظل أو أيقونة) ولا تنزّل أي صورة.
