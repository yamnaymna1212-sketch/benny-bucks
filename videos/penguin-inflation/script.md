# EP2 "Inflation explained with fish" — v3 (caveman-English style of the reference, ~62 s)

1. Snow cone cost one fish. Now snow cone cost two fish. Doug confused.
2. This is Doug. Doug is penguin. Doug has fish.
3. If penguins have few fish, fish rare. Fish valuable.
4. But Big Seal has fish machine.
5. Brrrrrr.
6. Big Seal make many, many fish.
7. Now fish everywhere. Fish common. Fish not valuable.
8. Snow cone cost more fish.
9. This called... money printing inflation.
10. Doug.
11. If all penguins want snow cone, but Puffin make same snow cones...
12. Snow cone become rare. Price go up.
13. Demand pull inflation.
14. Doug.
15. If ice cost more for Puffin...
16. Puffin pay more. Puffin charge more.
17. Cost push inflation.
18. Humans have this too. Since 2020, human prices go up twenty-three percent.
19. Doug buy snow cone. Doug eat snow cone. Life is good.
20. Doug check wallet.
21. Life is not good.
22. Which one get you? Fish machine, demand, or cost? Tell Doug in comments.

Fact: US CPI-U Jan 2020 257.971 -> Jan 2025 317.671 (BLS) = +23%.
Terms are used correctly (the reference mislabels cost-push vs supply): money printing = more money same goods;
demand-pull = more buyers same goods; cost-push = seller's costs rise.
