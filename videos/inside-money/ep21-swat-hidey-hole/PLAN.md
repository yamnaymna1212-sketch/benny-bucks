## Rules (from PROJECT_BRIEF section 0 + memory)
- Camera: one continuous move, no hard cuts, no shake, no haze; subject centred; something changes every ~2 s.
- Voice: one Kokoro take am_liam speed ~0.95, max_gap .08, 61-65 s; cut lines (see SCRIPT.md) instead of speeding up.
- SFX: few (hook <= 4 cues), trimmed so they never bleed.
- Process: build hook (0-5 s) -> stills check -> 5-s hook preview to the user -> full render only after approval -> phone copy < 30 MB -> PUBLISH.md + title/hashtags pasted in chat.
- Note: off-niche one-off test; keep it non-violent (no injuries, no weapons fired).
