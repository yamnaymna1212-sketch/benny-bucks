# EP22 facts (checked on IRS.gov 2026-11-14)
- Qualified tips deduction ("no tax on tips", IRC 224): tax years 2025-2028, max $25,000/yr, no need to itemize. https://www.irs.gov/newsroom/working-families-tax-cuts-tax-deductions-for-working-americans-and-seniors
- Phase-out: reduced when MAGI > $150,000 ($300,000 joint). Same page + final regs T.D. 10044 (effective 2026-06-12) https://www.irs.gov/irb/2026-18_IRB
- Must be voluntary cash/charged tips (or tip-sharing), in an occupation on the IRS list; SSN on return; married must file jointly; SSTB owners/employees excluded. Same IRS page.
- List: 71 occupations in 8 categories; includes Bartenders (TTOC 101), Wait staff (102), Barbers/hairdressers/cosmetologists (603), Taxi + rideshare drivers (802). https://www.irs.gov/forms-pubs/occupations-that-customarily-and-regularly-received-tips-on-or-before-dec-31-2024 ("more than seventy" in the script = safe)
- Employers/payors report cash tips + occupation to IRS/SSA; 2026 W-2 adds Box 12 code TP + Box 14b TTOC (W-2s issued Jan 2027). IRS page above + draft 2026 W-2.
- FICA: the deduction does NOT apply for FICA; tips remain wages for Social Security + Medicare. Employee share 6.2% + 1.45% = 7.65% (2026 SS wage base $184,500). https://www.irs.gov/taxtopics/tc751 + IRB 2026-18 (T.D. 10044)
- Math: $25,000 x 7.65% = $1,912.50 -> script says "nineteen hundred twelve dollars" (floored; rounding to $1,913 also fine). Never claim an income-tax saving amount (depends on bracket).
- State tax: depends on each state's conformity (some conform, some decoupled, e.g. CA reported as not conforming). Script only says "your state MAY still tax your tips" (Ballotpedia 2026-05-28: 19 states conformed; verify per state).
- Not verified on IRS.gov (do not say): exact penalty amounts, state list.
