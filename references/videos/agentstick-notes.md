# agentstick — frame analysis (4 phone screenshots, "How money runs the world")
Learn techniques, never copy scenes/characters.

- Layout: top ~40% illustrated mini-scene (floating land masses, characters, objects); middle = ONE huge bold word synced to the voice (TO, COUNTRIES, BILLIONS, IMF); bottom ~50% stick-figure narrator reacting (hand on chin, raised arm, worried brow lines).
- Full-frame scenes alternate in for big moments (Greek street with loan paper, coin jar; USA land with IMF building + "1944" block), word still centered.
- Pacing: visual change every 1–3s; narrator pose changes per sentence.
- Palette: white bg, black outlines, few strong accents (grass green, sand gold, flag red/blue).
- Metaphors as objects: money bags with loan notes, balance scale, cracked dry land vs green land, bank building, coin jar.
- Labels: 1-word tags on objects only (BANK, LOAN, IMF, 1944).
- Font: heavy, slightly slanted brush-bold, black, no outline, centered.
- Caution: uses recognizable real politicians; we use original/fictional characters only.
