# Benny Bucks video style

Short vertical finance stories where Benny lives through a money situation and the viewer learns with him. It must feel like a story unfolding, not a slideshow.

## Non-negotiables
1. Benny only (never a penguin); consistent design from approved assets.
2. Simple 2D hand-drawn look: wobbly black outlines, flat colors, white background, minimal detail.
3. Something changes on screen at least every ~2 seconds (expression, pose, object, or camera).
4. Scenes connect: each one continues the previous action, place, or object.
5. Voiceover only, no music.
6. Every number is accurate, with a source or shown calculation.
7. Original script and composition every time; never copy reference videos.

## Workflow
1. Topic + key number(s) → verify math/sources.
2. Script using the 6-part story structure.
3. Break into scene cards.
4. Check the scene cards against the checklist below.
5. Only after user approval: assets, animation, voice, render.

## Final checklist
- [ ] Hook in first 3s, with a strong visual contrast
- [ ] Benny on-model in every scene
- [ ] No still scene; no gap over ~2s without change
- [ ] Each transition is motivated by the story
- [ ] Numbers verified; sources noted
- [ ] Key text inside safe zone; voice clear; no music
